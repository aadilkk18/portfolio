## How it's built

No framework and no build step. Plain HTML, CSS and vanilla JavaScript, so it loads fast and there is nothing to break.

- Dark theme by default, with a light theme saved in the browser
- Design tokens in one stylesheet (`assets/css/style.css`)
- Project cards are generated from a single data file (`assets/js/projects.js`)
- Fonts: Inter Tight, Inter, JetBrains Mono
- Hosted on GitHub Pages

## Run it locally

1. Clone the repo.
2. Open the folder in VS Code and start the **Live Server** extension, or run `python -m http.server 5500` in the folder.
3. Open `http://127.0.0.1:5500/`.
